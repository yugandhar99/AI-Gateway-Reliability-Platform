# AI Inference Orchestration Platform v2.0.0

This release candidate extends the independent AI gateway portfolio project with durable asynchronous inference. Customers can submit jobs, poll status, retrieve results, and cancel active work. The existing synchronous chat and tenant usage APIs remain available.

Jobs share a SQLite database with quota reservations and settlement. The scheduler prioritizes ready jobs and ages long-waiting work. Concurrent workers renew claims through heartbeats. Expired claims are recovered during polling, and a stale worker cannot renew or settle them. Failed attempts retry with capped exponential delay before reaching a durable dead-letter state. Global and tenant queue limits return HTTP 429 with a retry hint.

## Upgrade and operate

Back up the SQLite volume before starting the new image. Keep one gateway replica and retain the same storage mount and tenant credentials so prior usage is preserved. Job tables are initialized at startup. Verify health, authenticated submission, worker progress, result retrieval, and accounting after deployment. A rollback that restores a pre-upgrade snapshot discards jobs and settlements after that snapshot, so drain or reconcile them first.

## Verification

The release evidence records 83 passing Python tests and 30 passing isolated Docker smoke checks. The five-worker integration accepted and completed all 100 jobs across three tenants on their first claim. Fault scenarios covered retries, worker loss, crash recovery, stale settlement rejection, and terminal-state persistence. The 18-panel Grafana dashboard includes six inference panels. These checks use simulated providers on a single host.
